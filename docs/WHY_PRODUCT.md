# 为什么做 AI 面试官，而不是「大模型 + Prompt」

通用聊天里复制一段「模拟面试 prompt」，可以完成一次练习。那不是竞品级方案，而是这个产品要替用户收掉的手工活。

**结论：** Prompt 解决「我会用 AI」；产品解决「按我的真实简历，用嘴被追问，练完有可核对的复盘」。商业上，可复制的提示词不能形成生意，可控的练习流程可以。

## 用户要买什么

目标用户是毕业生和初入职场者。他们要的不是更长的指令，而是：

- 用这份 JD 和这份简历，被问得像真面试
- 一次一题，追问「为什么 / 你做了什么 / 结果是多少」
- 用嘴答，而不是打字写作文
- 不许帮我编经历；宁可问到答不上
- 结束后告诉我：哪里会被刷、哪段能打、下次补什么

Prompt 把方法写给人看。产品把方法做成默认行为，使用户不必当提示词工程师，也不必当模型质检员。

## Prompt 做得到，和做不到

把「不许编造、要引用原话、没证据就别打分」写进 Prompt，方向是对的，模型多数时候也会尽量配合。过不去的是结构：

| | 大模型 + Prompt | 本产品 |
|---|---|---|
| 规则 | 请求模型遵守，上下文一长就衰减 | 阶段、追问上限、停问条件在程序里 |
| 简历 | 一「分析」就容易总结、拔高、补全 | 抽取 → 脱敏 → 用户确认后才开面；上下文不改写事实 |
| 幻觉 | 生成者和裁判是同一个模型 | 模型只提议；引用须在回答里逐字核对，对不上则作废 |
| 打分 | 每题 10 分易变成无依据鉴定 | 六维有锚点；无证据不评分；流畅度用语音实测 |
| 练习形态 | 默认打字，边面边教 | 语音优先；场上当面试官，面完再复盘 |

同一类大模型，差别不是「我们的模型更听话」，而是 **编造进不了成绩单，看不见的维度不许打分。** Agent / Skill 的意义是分工和权限：一次调用只做窄任务，事实权和流程权不交给模型。

## 商业上为什么必须做成产品

1. **Prompt 没有护城河。** 爆款指令可以被转发、改写、贴进任何聊天框。用户关系和付费入口在 ChatGPT / 豆包，不在写 prompt 的人。产品收的是账号、场次、简历和报告，才能定价、限额、复访。

2. **付费用户买的是稳定结果，不是一次灵感。** 若体验等于免费聊天，价格必输给「我已有的大模型」。能收费的点是：质量可预期、不帮用户练假故事、报告能对质、支持反复开场和专项弱项。信任被幻觉打穿，口碑和续费一起掉。

3. **目标客户不会运营 Prompt。** 校招生要的是点开始就面。把质检推给用户，转化停在「会玩 AI 的一小群」；做成产品才能覆盖真正量大的备考人群。

4. **语音 + 结构化场次，才是可卖的练习场景。** 真面试卡的是开口。打字彩排和现场不是同一技能。按场计次、按日限额、按专项训练，也比「一段无限聊天」更好做套餐和内测配额。

5. **B 端和渠道要的是闭环，不是一篇帖子。** 高校就业、训练营、招聘方内训，无法把「请学生自行粘贴 2000 字指令」当交付。他们要统一流程、隐私脱敏、账号隔离、可抽查的报告。这些只存在于产品里。

6. **数据飞轮只发生在结构化练习上。** 哪类追问有效、哪类空话被问穿、报告哪一维总是证据不足，能反过来改题库策略和转化。散落在各家聊天记录里的 prompt 会话，形不成你的资产。

7. **风险和品牌。** 若系统帮用户编项目和数据，真实面试穿帮会被算到产品头上。把「不编造」做成验收而不是口号，是获客成本，也是合规和口碑成本。

## 对外一句话

通用 AI 给你一段可复制的面试官人设；我们做成一个按确认简历和岗位来的模拟面试官——用嘴答、被追问、假经历和假评语过不了核对。Prompt 是方法说明书，产品是把方法变成可收费、可复用、可对质的练习服务。
